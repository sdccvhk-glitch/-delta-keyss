# DELTA.KEYS — Railway-ready

New dark theme, white readable text, working homepage and admin login routes.

## Railway
- Start command: `npm start`
- Railway automatically supplies `PORT`.
- Optional variables: `ADMIN_USER`, `ADMIN_PASSWORD`, `PAYMENT_UPI_ID`, `PAYMENT_PAYEE_NAME`, `PAYMENT_NOTE`.
- Default admin credentials if variables are not set: `admin` / `change-this-password`.

Open `/` for the store and `/admin` for admin login.
