# DELTA.KEYS FINAL

## Railway Variables
Set these exact variables in your Railway service:

- ADMIN_EMAIL = your admin email address
- ADMIN_PASSWORD = your admin password
- ADMIN_SECRET = your admin secret code

Do not use ADMIN_USER.

The admin email is trimmed and compared case-insensitively.
Password and secret code must match exactly.

Admin login can be remembered for 24 hours. Logout clears the saved session.
